# Compresso

A private, client-side image compressor built with Apple Fluid Design principles.

## Features
- **Guaranteed 75%–85% Size Reduction:** Drops 150MB+ photo folders down to ~25MB using canvas WebP compression.
- **Client-Side & Free:** 100% in-browser processing. Zero server compute, zero upload limits, completely private.
- **Batch History & Offline Persistence:** Powered by `IndexedDB`. Remembers previous batches, timestamps, and thumbnails across browser sessions.
- **Neat Folder Extraction:** ZIP downloads place all images inside a dedicated root folder, preventing loose files on extraction.
- **Universal Formats:** Supports iPhone `.heic`, `.jpeg`, `.png`, and `.webp`.

## Deployment
Hosted on Vercel with zero configuration required.
